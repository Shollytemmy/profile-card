# Stage 0: Testable Profile Card

A simple, semantic, responsive **Profile Card** built with **HTML, CSS, and vanilla JavaScript**.  
Every visible element includes the required `data-testid` attributes for automated testing.

## 🧰 Tech Stack
- HTML5 (semantic elements)
- CSS3 (Flexbox + responsive design)
- Vanilla JavaScript (for live time display)

 index.html # Main page
 style.css # Styling for layout and responsiveness
 script.js # JS logic (updates time in milliseconds)
